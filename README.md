# 👻 WAKE

> **Your past is hunting you. Use it.**

An arcade survival game that runs in your browser. A ghostly **echo** retraces your path a few seconds late. It kills you if it touches you, but it is also your only weapon.

**[▶ Play now](https://wake-lemon.vercel.app)**

## How to play

- Survive as long as you can. One touch from an enemy or your own echo ends the run.
- Lead the pink **wisps** along your trail so your echo sweeps through them. Kills chain-react for bonus points.
- Collect gold **orbs**: 5 awaken a second echo, 12 a third.
- **Phase** lets you pass through anything for 0.75s (4s cooldown).
- Run in wide loops. Tight circles run you into your own echo.

## Controls

| | Desktop | Mobile |
|---|---|---|
| Move | Mouse or WASD / arrows | Drag anywhere (floating joystick) |
| Phase | Space or click | PHASE button or second finger |
| Pause | P / Esc | ❚❚ button |
| Rules | H / ? | ? button |

## Tech

Single HTML file. Vanilla JavaScript, Canvas 2D, Web Audio. No dependencies.
